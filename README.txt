生物ランダム図鑑 iNaturalist版
==============================

これはGBIF版とは別のアプリです。既存のGitHubリポジトリは変更せず、新しいリポジトリにアップロードしてください。

データの仕組み
--------------
・iNaturalist API v1の観察記録を使用します。
・日本語ロケール(locale=ja)で取得し、和名(preferred_common_name)がある種だけを採用します。
・種(species)ランクで、観察写真が付いた記録だけを候補にします。
・ランダム順の観察記録を一度に最大200件取得し、種の重複を除いて端末内の候補プールにします。
・抽選は候補プールから行います。1回の抽選内では、可能な限り同じ属(genus)が重ならないようにします。
・分類群ごとの抽選重みを下げる機能、抽選履歴、オートモードを搭載しています。
・画像をタップすると詳細オプションが開きます。「分類群の確率を下げる」「GBIFで詳細」「iNaturalistで観察記録」を選べます。

注意・制限
----------
・iNaturalistのデータは世界中の観察記録に基づくため、全生物種の完全な一覧ではありません。写真付きの観察がない種や、日本語名がiNaturalistに登録されていない種は対象外です。
・ランダム抽選はランダム順の観察記録から候補を集める方式です。全種が同じ確率になることを保証するものではありません。観察数が多い種ほど候補に現れやすい偏りは残ります。
・画像は観察者が投稿した写真です。写真の被写体が画面いっぱいに写っているとは限りませんが、論文図版を除外しやすい方式です。
・写真の利用条件は投稿ごとに異なります。詳細画面に表示されるクレジットとライセンスを確認してください。
・APIと画像の読み込みにはインターネット接続が必要です。アプリ本体のみオフラインキャッシュされます。
・iNaturalistはAPIを毎分60リクエスト以下で利用することを推奨しています。本アプリは候補プールが不足した時だけまとめて取得する設計です。

インストール
------------
1. GitHubで新しいPublicリポジトリを作成（例: seibutsu-zukan-inat）。
2. ZIPを解凍し、中の5ファイルをリポジトリの最上位にアップロード。
   index.html / manifest.webmanifest / sw.js / icon.svg / icon-180.png
3. Settings > Pages > Deploy from a branch を選択。
4. Branch: main、Folder: /(root) を選択してSave。
5. 公開されたURLをiPhoneのSafariで開き、共有ボタン > ホーム画面に追加。

更新時は5ファイルを同じように上書きしてCommit changesしてください。
