生物ランダム図鑑 拡張版
========================

導入
1. ZIPを展開します。
2. GitHub Pagesで公開しているリポジトリのルートに、同名ファイルを上書きアップロードします。
3. GitHub Pagesの反映後、Safariでページを再読み込みします。
4. iPhoneのホーム画面アプリは、一度終了してから再起動してください。

候補の増やし方
- 「候補を追加取得」を押すと、分類群ごとに最大5ページ（最大約1,000件）を取得します。
- 日本語の一般名と写真が両方ある種だけを登録します。
- API負荷を避けるため、リクエスト間隔は約1.1秒です。
- 10,000種は目標であり、実際の登録数はアプリ上部の「登録済み種」に表示されます。
- 取得できる種数はiNaturalist側の日本語名・写真データの有無に依存します。

データ保存
- 生物データはIndexedDB、抽選履歴はlocalStorageに保存します。
- ブラウザのサイトデータを消すと消えるため、「データを書き出す」でバックアップできます。
- 別端末へ移す場合は書き出したJSONを新端末で読み込んでください。

注意
- iNaturalist APIの応答や分類データは更新されることがあります。
- 写真の利用条件は写真ごとに異なります。アプリはAPIのライセンス情報・帰属情報を詳細画面に表示します。
- この版はライブ取得型です。10,000件のデータを最初からZIPに同梱しているわけではありません。
- 自動抽選は現在保存済み候補から抽選します。候補が不足すると追加取得を試みます。
